# AI_GUIDELINES.md

This file is now a pointer, not the authoritative ruleset.

For Codex skill-based guidance, the repository-wide source of truth is:

- `.codex/skills/tarr-pop-repo-guard/SKILL.md`
- `.codex/skills/tarr-pop-repo-guard/references/repo-guidelines.md`

Reason:

- skill files are discoverable by Codex's skill system
- keeping the guidance in one skill avoids two competing instruction sources
- task-specific `tarr-pop-*` skills can now rely on one shared repo guard

Human contributors can still read the skill reference file directly.
